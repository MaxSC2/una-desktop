## 1. Findings (Что обнаружено)

1. **F-кандидат (TASK-007, meta-learning.ts):** все русскоязычные regex-паттерны используют `\b` (word boundary). В JS `\b` опирается на `\w` = `[A-Za-z0-9_]` → граница слова с кириллицей никогда не совпадает. Итог: `detectCorrection`/`learnFromMessage` игнорируют ЛЮБОЙ русский ввод — детекция поправок и предпочтений для RU-пользователя мертва. Прод-код не тронут (P1-2); тесты зафиксировали фактическое поведение (EN-паттерны). Требуется решение Архитектора (замена `\b` на lookaround-класс с `\p{L}` или явные границы).
2. **Monologue quirk:** curiosity-мысль при 0 наблюдений/0 ссылок получает тип `'reflection'` (условие `0 > 0` === false). Задокументировано в спеке TASK-005.
3. **World-model flake:** `sessionId` строится из `Date.now()` → сброс сессии в ту же миллисекунду даёт тот же id. Тест дефлейкнут через `vi.spyOn(Date,'now')` (коммит `8b7675a`).
4. **Life-loop perf-ловушка:** интервал 30 с при fake-timers прокрутке часов = тысячи тиков → таймаут; тест night-maintenance использует `tickIntervalMs: 10_000` (коммит `a557494`).
5. **PR #1 (chore/k3-task-001-prep) — MERGED 2026-09-22** (коммит `3e80ae4` в main). PR #2 (TASK-001 tests, `k3/task-001-compression-tests`) остаётся OPEN, ждёт approve (ruleset review-gate).
