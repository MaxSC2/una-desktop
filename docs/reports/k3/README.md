# docs/reports/k3 — отчёты автономных заходов K3

Каждый автономный заход K3 завершается отчётом `YYYY-MM-DD-<task>.md` в этом каталоге.
Контракт отчёта (DEC-021, спецификация — `docs/research/k3-autonomous-workzone-proposal.md` §5):

```
## Отчёт K3 — <дата> — <задача>
- Основание: <задача / Accepted DEC / пункт backlog>
- Ветка: k3/<task>  ·  Коммиты: <хэши, один = одна задача>
- Проверки: tsc electron <n> · tsc renderer <n> · vitest <passed>/<total> · build ✓/✗ · manifest <n>/<n>
- Отклонения от плана: <что и почему>
- Обнаружено (facts): <находки, как в JOURNAL>
- PROPOSED (PENDING APPROVAL): <идеи/DEC-драфты, НЕ решения>
- Блокеры/эскалации: <по §6 спецификации>
```

Правила:
- отчёт — данные для разбора lead'ом, не место для решений; новые идеи — только как PROPOSED;
- счётчики проверок обязательны — без зелёных проверок задача не считается выполненной;
- стоп-условия и эскалация — `k3-autonomous-workzone-proposal.md` §6.
