### self-review.ts (проверки)
1. **Fix 0 подтверждён тестами как дефект устранён**: до фикса RU-фразы не матчились вообще
   (`\b` мёртв рядом с А-Я) — «какая погода?» при 0 инструментов не получало штраф web_search,
   «Привет, как дела?» не требовал приветствия в ответе, «Да, …» не считался прямым ответом.
2. needsWeb-список **RU-only** (эдж, не фикс): «What is the weather today?» с 0 инструментов —
   без штрафа.
3. `clamp [1,5]` работает: сумма штрафов >4 → ровно 1.
4. Обрезки: userMessage 200, responsePreview 300; cap in-memory 20 (unshift+pop).
5. `runDeepReview`: **битый JSON исключается из суммы score, но остаётся в делителе** —
   averageScore занижается (1 валидный score 5 + 1 битый → 2.5, а не 5).
   Факт без `score` → вклад 3 (default).
6. `saveFact` при ошибке → `console.warn`, ревью не падает.

### vram-gate.ts
7. `isModelLoaded` при non-ok/throw → **true** (консервативно: не выгружаем вслепую).
8. `lastUnloadAt=0` при старте модуля: первая выгрузка блокируется 60с-кулдауном, если
   `Date.now() < 60_000` (в тестах время сдвинуто; в реальности от epoch это неактуально).
9. Fail-кулдаун: неудачная выгрузка блокирует повторы 120с (fetch не вызывается вовсе).
10. `wasGaming`: сброс только при первой не-gaming проверке после gaming (лог один раз).
11. Двойной `startVramGate` → один таймер (early return по `timer !== null`).

### asr.ts
12. `provider local` + любой провал → throw **без облачного fallback**; `auto` → fallback.
13. `auto` без `whisperPath` → локальная ветка пропускается, сразу облако.
14. Очистка tmp: входной `.wav` удаляется до проверки кода выхода; `.txt` — после чтения.
    `data:audio/...;base64,`-префикс счищается и для local, и для cloud (assert по `file_base64`).
15. Тексты ошибок несут код выхода и stderr (`exited 1: bad model`).

### tts.ts
16. `provider local` + провал Piper → `{ '', 'none' }`, **не throw** (graceful);
    `synthesizeCloud` при пустом ответе кидает исключение, которое проглатывается в `synthesize` →
    тоже `{ '', 'none' }`. Наружу synthesize не кидает ни в одном кейсе.
17. Вход облака обрезается до 1500 символов; `response_format: 'mp3'` жёстко зашит.
18. WAV-заголовок корректный: RIFF/WAVE, 44 байта, PCM-данные копируются как есть; запуск
    Piper всегда с `--output-raw` (22050 Hz/16 бит/моно — зашито в pcmToWav).
