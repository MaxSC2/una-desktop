# U.N.A. Conversation Field v0.3

Изолированный дизайн-прототип. Production-код не изменён.

Открыть `index.html` напрямую в браузере.

## Гипотеза

v0.1 доказал motion/state mechanics, но выглядел как dashboard.
v0.2 убрал dashboard-объекты, но conversation field всё ещё был слишком
близок к техническому списку сообщений.

v0.3 проверяет гипотезу:

> разговор имеет геометрию, но не превращается в чат-панель.

## Композиция

PRESENCE → CONVERSATION FIELD → DOCK.

Presence остаётся центром сущности. Conversation Field находится ниже,
имеет невидимый центральный rail и две стабильные стороны. Пользователь
всегда появляется слева, Юна — справа. Это не bubbles и не две карточки:
это две позиции в одном разговорном пространстве.

Сообщения образуют вертикальный поток. Последняя реплика активна.
Предыдущая становится тише. Максимум шесть видимых сообщений.

## Что изменено относительно prototype-scene-v0.2

- Убран текстовый placeholder из активного поля.
- Conversation Field получил явную пространственную ось.
- USER/YUNA получили стабильные колонки без рамок.
- Разделение держится типографикой и маленьким точечным маркером.
- Streaming изменяет один DOM-объект, не создавая вторую реплику.
- Presence area увеличена до 246×202, placeholder остаётся внутри неё.
- В SPEAKING halo приглушён, чтобы активный текст был сильнее свечения.
- WORKING показывает pocket как единственную surface-card.
- Header остаётся только U.N.A. + время.

## Почему не bubbles

Bubble автоматически превращает U.N.A. в messenger UI.
Нам нужен разговор в пространстве, а не набор карточек сообщений.

## Eye-test

C1. В IDLE presence воспринимается как сущность, а не status icon.
C2. Без рамок понятно, где пользователь говорит, а где отвечает Юна.
C3. При 2–6 репликах поле не выглядит случайно разбросанным.
C4. Нет chat card/dashboard.
C5. В WORKING pocket остаётся единственной surface-card.
C6. CENTER → RIGHT сохраняет одну сцену.
A11. Состояние считывается без знания внутренних типов.

Дополнительно:
- длинная реплика;
- 6+ сообщений;
- USER → YUNA → USER → YUNA;
- streaming без дубля;
- Esc во время streaming;
- WORKING → HAPPY → CENTER.

## Управление

`1` — IDLE
`2` — SPEAKING
`3` — WORKING
`Esc` — остановить

Это служебные клавиши прототипа, не часть интерфейса.
