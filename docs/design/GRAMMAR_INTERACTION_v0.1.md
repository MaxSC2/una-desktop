Interaction grammar v0.1 — что можно трогать и что замечает Юна.

Статус: часть Presence Design v0.1. Код не трогаем.
Связано: UNA_PRESENCE_DESIGN_v0.1.md, GRAMMAR_VISUAL_v0.1.md,
wireframes 01–05. Маппинг на код — только именами существующих сущностей.

1. Что пользователь может трогать (touchable, всего 5 точек).

INPUT (Dock). Единственная точка ввода текста. Один на все состояния.
  Enter — отправить. Esc во время генерации — стоп (как кнопка Стоп).
  Промежуточный ASR-текст показывается в input italic (не отправлен).
MIC (Dock). Тумблер голосового ввода (startListening/stopListening уже есть).
  Состояния иконки: тусклый / эквалайзер (TTS идёт) / красный+волна
  (слушаю) / зачёркнут (DnD, gaming, meeting, SLEEPING).
STOP (Dock, видна только в WORKING/SPEAKING). Останавливает генерацию
  или задачу (chat:stop уже есть). Переводит WORKING→IDLE или SPEAKING→IDLE.
  После стопа pocket показывает «Остановлено», результат не выдумывается.
TABS (Dock): Chat / Tasks / Memory / System. Переключают ФОКУС правой панели,
  не сцену. Юна остаётся на месте (P2). Активный таб — violet рамка,
  остальные — тусклые. Таб не уводит Юну из зоны.
POCKET-CONTROLS (внутри activity pocket): раскрыть лог (кат), остановить шаг,
  Подтвердить/Отмена (awaiting_confirmation живёт здесь, не модалкой).
  Закрыть pocket крестиком можно только в IDLE (в WORKING pocket обязателен).

Всё остальное — НЕ touchable в v0.1: аватар не кликается (не питомец),
фон не кликается (drop-зона — будущее), presence line не кликается
(это голос Юны, не кнопка), реплики не редактируются (только копирование).

2. Что Юна сама замечает (observable, без кликов пользователя).

Источники уже есть в коде: attention-manager (focus, interruptible,
responseUrgency, allowProactive, allowSound), world-model (время, сессия),
states.ts (sleep/idle/gaming/night/active), resource-manager (activity).
Грамматика фиксирует только КАК это выглядит, не как вычисляется:

- deep_focus / gaming / meeting → OBSERVING: SHIFT в LEFT, DIM −20%,
  mic зачёркнут, proactive молчит. Юна не исчезает — она ждёт рядом.
- chatting (burst + <1 мин) → CENTER, responseUrgency immediate:
  presence line короче, ответы без предисловий.
- idle > 5 мин → BOTTOM: слот опускается, dim лёгкий.
  idle > 15 мин или ночь → SLEEPING (wireframe 04).
- ночь 23–6 → DIM −30%, звук off, proactive off (раздел 9 главного документа).
- awaiting_confirmation (риск caution/dangerous) → CONCERNED-слой:
  pocket раскрывается сам, amber акцент, Юна на месте.
- tool_done / задача готова → HAPPY-слой 1.5s → pocket схлопывается.

Юна НИКОГДА не замечает вслух то, что пользователь не просил озвучивать:
никаких «я вижу, ты в игре!» посреди gaming. OBSERVING — молчаливое.
Исключение — OVERLAY и только срочное (упавшая сборка, риск потери данных).

3. Как обычный UI-объект становится частью присутствия (обряд из 3 шагов).

Любой новый контрол в v0.1 обязан пройти проверку:
Шаг 1 — Классифицируй (visual grammar): это Space, Reaction или Information?
  Если Information — ему место в strip, pocket или Dock. Не рядом с Юной.
Шаг 2 — Дай движение из словаря (motion grammar): APPEAR 400ms при
  появлении, reverse 300ms при уходе. Никаких своих easing и длительностей.
Шаг 3 — Свяжи с присутствием: что происходит с Юной, когда объект появляется?
  Примеры: pocket раскрылся → Юна SHIFT RIGHT. Подтверждение появилось →
  CONCERNED-слой. Ошибка залогирована → ERROR-слой до прочтения.
  Объект без связи с присутствием — лишний объект, удалить.

Разобранные примеры (канонические, на них равняться):
- Кнопка Стоп: Information (Dock) → APPEAR только в WORKING/SPEAKING →
  связь: клик = WORKING→IDLE + pocket «Остановлено».
- Лог шагов: Information (pocket, под катом) → APPEAR по шагам 100ms
  по очереди → связь: текущий шаг пульсирует, Юна LEAN к pocket.
- Подтверждение риска: Information (pocket) → APPEAR + CONCERNED-слой
  одновременно → связь: Юна не двигается (остаётся CENTER), только GLOW amber.
- ASR-текст: Information (input italic) → связь: MIC красный+волна,
  Юна LISTENING-кольцо. Отправка — как обычный INPUT.
- Время в Header: Information (не трогать) → связи с Юной нет,
  это Space-подпись. Исключение, подтверждающее правило.

4. Запрещённые взаимодействия (v0.1).

- Клик/тап по аватару ничего не делает (не тыкать Юну).
- Drag аватара по экрану нет (зоны меняет только состояние, не рука).
- Свайпы не меняют зону (мобильный свайп = скролл strip, не SHIFT Юны).
- Никаких контекстных меню на Юне.
- Никаких бейджей/счётчиков поверх слота (не завешивать присутствие цифрами).
- Overlay нельзя вызвать вручную — только система и только срочное.
