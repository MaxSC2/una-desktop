Motion grammar v0.1 — как Юна движется.

Статус: часть Presence Design v0.1. Код не трогаем.
Связано: UNA_PRESENCE_DESIGN_v0.1.md (разделы 3, 5, 13), wireframes 01–05.

Принцип: движение = смысл. Нет декоративных анимаций.
Каждое движение отвечает на вопрос «что изменилось в присутствии?»

1. Базовый словарь (всего 6 примитивов, больше нельзя без пересмотра грамматики).

BREATHE — медленное дыхание glow/scale. Цикл 4s, amplitude scale 1.0→1.03.
  Где: IDLE всегда, SLEEPING едва заметно (amplitude x0.3), OBSERVING норма.
  Запрет: никогда не ускорять BREATHE для «важности». Важность = другой примитив.

LEAN — лёгкое покачивание/наклон в сторону фокуса. Amplitude ±4px, период 3s.
  Где: SPEAKING (к пользователю), THINKING (замирание = LEAN с amplitude 0,
  остаётся только BREATHE быстрее 2s).

SHIFT — смена зоны (CENTER→RIGHT→LEFT→BOTTOM→SLEEP).
  Длительность 500ms, easing ease-in-out, только transform translate + opacity.
  Никаких bounce, overshoot, spring. Сцена не пересобирается: слот едет,
  остальное кроссфейдится. Самый частый SHIFT CENTER→RIGHT (ответ → действие).

APPEAR — появление. Кроссфейд 400ms + translateY 8px снизу вверх.
  Где: новая реплика в strip, раскрытие pocket, presence line смена.
  Исчезновение — тот же APPEAR в обратную сторону, 300ms. Никаких схлопываний
  с подпрыгиванием соседей: соседний контент заранее резервирует место.

GLOW — смена цвета/интенсивности ореола. Кроссфейд 600ms между токенами.
  Один акцент за раз (см. токены в главном документе). Glow не мигает.
  Исключение: текущий шаг в pocket может пульсировать (opacity 0.6↔1.0, 1.5s),
  но это Information-слой, не Юна.

DIM — приглушение сцены. Кроссфейд 2s (день→ночь) или 600ms (→SLEEPING).
  DIM −20% OBSERVING, −30% ночь, −60% SLEEP. Возврат из DIM всегда медленнее
  (600ms), чем вход: пробуждение мягче засыпания.

2. Переходы между зонами (таблица, все пары через SHIFT 500ms).

CENTER→RIGHT (говорила → делает): слот едет вправо, pocket APPEAR справа,
  strip замирает (автоскролл off), presence line меняется на «Делаю: X».
CENTER→LEFT (говорила → не мешает): слот едет влево + scale до 120px,
  DIM −20%, presence line гаснет (APPEAR reverse), mic зачёркивается.
RIGHT→CENTER (сделала → отвечает): pocket APPEAR reverse 300ms, слот
  возвращается, HAPPY-слой 1.5s (subtle green), результат в strip одной строкой.
ANY→SLEEP: DIM 600ms + SHIFT в центр-уменьшенный + presence line «Сплю…».
SLEEP→CENTER: DIM reverse 600ms + SHIFT, presence line «Я тут».
CENTER→OVERLAY: только срочное. Overlay APPEAR поверх (400ms), сцена под ним
  DIM −30%. Закрытие — reverse, сцена возвращается без перезагрузки.

3. Взгляд и внимание (без глаз — через позицию и свет).

Юна «смотрит» туда, где её зона: CENTER = на пользователя,
RIGHT = на задачу (слот повёрнут/наклонён к pocket на 4px — LEAN вправо),
LEFT = в сторону (наклон от пользователя). Когда глаз нет (ромб/orb),
взгляд читается по LEAN + glow-направлению (градиент ореола смещён
к фокусу на 10%). Когда глаза появятся (Rive/Live2D) — тот же словарь,
зрачки повторяют LEAN.

4. Реакции поверх состояния (слои 1.5s, потом возврат).

HAPPY: GLOW к subtle green 600ms → держать 1.5s → GLOW обратно к violet.
  Плюс одна волна BREATHE глубже (scale до 1.05 один раз). Всё.
CONCERNED: GLOW к warm amber + LEAN amplitude x0.5 дрожание (не тряска).
  Держать пока висит подтверждение. Снятие — GLOW обратно 600ms.
ERROR: GLOW к restrained red 0.6, без пульсации. Держать до прочтения.
  Никакого мигания. Текст ошибки — Information, не часть Юны.

5. Бюджет движения (защита от цирка).

Одновременно на экране: максимум 1 SHIFT + 1 GLOW + фоновый BREATHE.
Запрещено запускать APPEAR реплики + SHIFT слота + GLOW в один кадр —
раскладывать по очереди с шагом 100ms (сначала SHIFT, потом остальное).
THINKING: только BREATHE 2s + строка «подумаю…». Больше ничего.
Если хочется добавить седьмой примитив — сначала доказать, что его смысл
не покрывается шестью. Подозрительные кандидаты (вращение, bounce,
parallax за курсором, частицы) — запрещены в v0.1.

6. Reduced motion.

При prefers-reduced-motion: BREATHE/LEAN off (статичный слот),
SHIFT заменяется кроссфейдом 200ms без перемещения (слот гаснет тут,
появляется там), GLOW — мгновенная смена без перехода, DIM — 200ms.
Смысл сохраняется (позиция конечная та же), движение убирается.
