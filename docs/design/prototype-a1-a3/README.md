# Prototype A1–A3 — отчёт (deliverables 2–6 ТЗ)

Статус: START выполнен. Открыть: `docs/design/prototype-a1-a3/index.html`
в браузере (двойной клик, без сборки). Production/backend не тронут:
весь прототип — 3 файла в `docs/design/prototype-a1-a3/`, вне `src/` и `electron/`.

Сценарий: кнопки `A1 IDLE / A2 SPEAKING / A3 WORKING / Готово → IDLE`
в demo-панели внизу. INPUT тоже работает: любой текст → SPEAKING.
STOP (в Dock и в pocket) → возврат IDLE. Esc в input — тоже стоп.

## 2. SPACE / REACTION / INFORMATION в прототипе

SPACE: `.space-bg` (3 слоя по токенам v0.1), `.stage`, `.living-stage`,
`.avatar-slot` как пустой бокс (размер фиксирован CSS, контент заменяем).
Зоны — только `body[data-zone]` → `transform: translateX` слота.

REACTION: `.avatar-glow` (цвет/интенсивность по `data-state`),
`.avatar-diamond` placeholder (ромб + имя ЮНА), `#voiceBars`
(3 столбика, только в SPEAKING), `#presenceLine` (одна строка).

INFORMATION: `.hud-header` (время + точка состояния, не кликабельны),
`.strip` (реплики, think-блок, стрим-курсор), `.pocket` (title, шаг,
прогресс, шаги, лог-кат, стоп), `.dock` (TABS/MIC/INPUT/STOP/Send).

## 3. Использованные motion-примитивы

| Примитив | Где | Параметры |
|---|---|---|
| BREATHE | `.avatar-glow` | 4s, scale 1.0→1.03, infinite |
| LEAN | `.avatar-diamond` | ±4px, 3s (SPEAKING тот же, смысл — наклон к фокусу) |
| SHIFT | `body[data-zone] .avatar-slot` | 500ms ease-in-out, только translateX |
| APPEAR | `#presenceLine`, `.msg`, `.pocket` | 400ms, opacity + translateY 8px |
| GLOW | `.avatar-glow`, `.hud-dot` | 600ms кроссфейд между токенами |
| DIM | не задействован в A1–A3 (нужен для OBSERVING/SLEEPING, вне скоупа) |

Не использованы и не добавлены: bounce, rotation, particles, parallax,
spring, overshoot. Voice-индикатор (3 столбика 0.9s) — часть слота
по грамматике, не новый примитив.

## 4. Отклонения от v0.1 (фиксирую как findings, грамматику молча не меняю)

F1. LEAN реализован через `margin-left ±4px`, а не `transform`.
Причина: ромб уже имеет `transform: rotate(45deg)`, второй transform
перетёр бы поворот. По грамматике LEAN должен быть transform.
Кандидат на правку грамматики или обёртку слота при реализации в React.
F2. Strip показывает 2–4 реплики через JS-trim, высота ограничена
`max-height: 40%` контейнера — визуально соответствует «не выше 40%»,
но точная метрика зависит от viewport. На прототипе ок, на проде мерить.
F3. HAPPY-слой (`data-state="happy"`, green 1.5s) добавлен как 4-е значение
`data-state` сверх трёх из ТЗ — но это слой из грамматики (завершение задачи),
не новое runtime-состояние. AssistantStatus не затронут (прототип вне рантайма).
F4. Demo-панель (`A1/A2/A3/Готово`) — служебный элемент прототипа,
не часть дизайна. В прод не переносить.

## 6. Проблемы, обнаруженные благодаря прототипу

P1. Переход RIGHT→CENTER после «Готово» визуально слабее, чем CENTER→RIGHT:
pocket исчезает за 300ms, а слот едет 500ms — 200ms слот висит без pocket
рядом. Возможно, слот должен стартовать с задержкой 100–200ms (бюджет
движения это разрешает: раскладка по очереди). Смотреть глазами на T1.
P2. В WORKING strip (opacity 0.75) и pocket рядом конкурируют за взгляд:
оба светлые на тёмном. Возможно, strip в WORKING приглушать сильнее
(до 0.6) — но это уже изменение грамматики, только после глазной проверки.
P3. Voice-столбики на ромбе 54px выглядят крупнее самого плейсхолдера.
На Rive/Live2D слот будет больше (220px бокс), проблема уйдёт сама —
но для ромба стоит уменьшить до 10px высотой. Мелочь, фиксирую.

## Проверка по T1–T3 + A11 (смотреть глазами как пользователь)

T1: A1 → A3 кнопкой — слот едет вправо, фон/сетка/HUD стоят, реплика
остаётся, pocket появляется справа. Если ощущается как новая страница — FAIL.
T2: в A3 зелёные галочки только в pocket (текст), glow Юны остаётся violet.
Свет = Юна, текст = статус. Не должно быть соблазна читать glow как прогресс.
T3: в A3 пульсирует только строка текущего шага в pocket (Information),
сама Юна дышит как в IDLE + LEAN к pocket. Она не мигает в такт шагам.
A11: без документации понятно: A1 «рядом», A2 «говорит» (столбики + стрим),
A3 «занята» (справа + pocket + BUSY). Типы и сущности знать не нужно.

(IDLE → SPEAKING → WORKING, кнопками demo-панели). Статичный markdown
их не заменит — смотреть в браузере.
