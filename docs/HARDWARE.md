# Аппаратные требования и оптимизация

## Ваше железо

> **CPU:** Intel Core i5
> **RAM:** 8 ГБ
> **GPU:** NVIDIA GTX 1650, 4 ГБ VRAM
> **OS:** (вероятно) Windows 10/11

**Вердикт: U.N.A. будет работать, но с оптимизациями.**

## Распределение ресурсов

### RAM (8 ГБ)

| Компонент | Использование |
|-----------|--------------|
| Windows + системные процессы | ~3 ГБ |
| Electron (renderer + main) | ~300-500 МБ |
| React UI | ~100 МБ |
| SQLite + embeddings cache | ~50 МБ |
| Ollama (если запущен) | ~500 МБ |
| **Итого** | **~4-5 ГБ** |

Остаётся ~3 ГБ под браузер, IDE, другие приложения. Тесно, но жить можно.

**Если RAM мало:** отключите Ollama, используйте только облачный LLM. Это сэкономит ~500 МБ.

### VRAM (4 ГБ GTX 1650)

| Модель | VRAM | Скорость |
|--------|------|----------|
| `qwen2.5:3b-instruct-q4_K_M` | ~2 ГБ | ~30-40 ток/сек |
| `llama3.2:3b` | ~2 ГБ | ~30-40 ток/сек |
| `phi3:mini` | ~1.8 ГБ | ~40-50 ток/сек |
| `gemma4:e2b-it-qat-2k` ← **текущая** | ~2 ГБ | TBD |
| `qwen2.5:7b-instruct-q4_K_M` | ~4.2 ГБ | ~15-20 ток/сек (НЕ влезет!) |
| Whisper small (для ASR) | ~500 МБ | real-time |
| Whisper medium | ~1.5 ГБ | ~1.5x real-time |
| LLaVA 7b (для VLM) | ~4 ГБ | ~10-15 ток/сек (НЕ влезет!) |

**Рекомендация для 4 ГБ VRAM:**
- LLM: `gemma4:e2b-it-qat-2k` (~2 ГБ) — текущая модель по умолчанию (см. `electron/ai/config.ts`)
- ASR: Whisper `small` (500 МБ)
- VLM: **только облако** (LLaVA 7b не влезет)
- Итого: ~2.5 ГБ VRAM — остаётся 1.5 ГБ запаса под систему

### CPU

i5 любого поколения справится. Самое тяжёлое — embeddings:
- `all-MiniLM-L6-v2` на CPU: ~10-20 мс на embedding
- Это приемлемо, не блокирует UI

## Оптимизации под слабое железо

### 1. Локальный LLM (Ollama)

Установите **Ollama** и скачайте лёгкую модель:

```bash
# Windows: скачайте installer с https://ollama.com
# После установки:
ollama pull gemma4:e2b-it-qat-2k
# Размер: ~2 ГБ на диске, ~2 ГБ VRAM при работе
```

В настройках U.N.A. выберите:
- LLM Provider: `local`
- Model: `gemma4:e2b-it-qat-2k`

**Преимущества:**
- Полный офлайн
- Никаких API ключей
- Приватность — данные не покидают ПК
- Бесплатно

**Недостатки:**
- 3B модель менее умная, чем 70B облачная
- Сложные задачи может делать хуже
- Занимает VRAM

### 2. Гибридный режим (рекомендуется для вас)

- Provider: `auto`
- Простые задачи (файлы, команды) — локально (быстро, бесплатно)
- Сложные задачи (код, анализ) — переключитесь на облако вручную
- VLM (анализ экрана) — только облако (LLaVA слишком тяжёлая)

### 3. Локальный ASR (whisper.cpp)

```bash
# Windows:
git clone https://github.com/ggerganov/whisper.cpp
cd whisper.cpp
mkdir build && cd build
cmake ..
cmake --build . --config Release

# Скачайте модель:
# https://huggingface.co/ggerganov/whisper.cpp/blob/main/models/ggml-small.bin
```

В настройках:
- ASR Provider: `local`
- whisperPath: `C:\path\to\whisper.cpp\build\bin\Release\whisper-cli.exe`
- modelPath: `C:\path\to\ggml-small.bin`
- language: `ru`

**Преимущества:**
- Офлайн
- Распознавание в реальном времени на GTX 1650
- Бесплатно

**Недостатки:**
- Менее точный, чем cloud (Whisper large)
- Требует CUDA для GPU ускорения (иначе CPU — медленнее)

### 4. Локальный TTS (Piper)

```bash
# Windows:
# 1. Скачайте piper: https://github.com/rhasspy/piper/releases
# 2. Скачайте голос: https://huggingface.co/rhasspy/piper-voices/resolve/main/ru/ru_RU/irina/medium/ru_RU-irina-medium.onnx
```

В настройках:
- TTS Provider: `local`
- piperPath: `C:\piper\piper.exe`
- voicePath: `C:\piper\ru_RU-irina-medium.onnx`

**Преимущества:**
- Офлайн
- Сверхбыстрый (~100 мс на предложение на CPU)
- Множество голосов
- Бесплатно

### 5. Облачный fallback (Z.ai)

Если локальные модели не установлены, U.N.A. автоматически использует облако:
- LLM: `glm-4.6` (мощная, но нужна сеть)
- ASR: `glm-asr`
- TTS: `nova` (женский голос)
- VLM: `glm-4.5v`

Получите API ключ на https://z.ai и вставьте в настройках.

## Что НЕ нагружает

- Работа с файлами (fs API) — практически бесплатно
- Выполнение команд — использует память команды, не U.N.A.
- Tray, hotkeys, overlay — миллисекунды

## Когда U.N.A. тормозит

1. **Сетевые задержки** — облачный LLM может отвечать 2-5 секунд. Решение: локальный Ollama.
2. **Загрузка VRAM** — если открыта игра или IDE с GPU ускорением, локальной модели может не хватить VRAM. Решение: закрыть тяжёлые приложения или использовать облако.
3. **Большая история диалогов** — 100+ сообщений замедляют LLM. Решение: starts новой conversation.
4. **Embeddings init** — первый запуск `@xenova/transformers` загружает модель ~5 секунд. Дальше кешируется.

## Резюме для вашего железа

**Оптимальная конфигурация:**

1. **LLM:** Гибрид (`auto`) — Ollama с `gemma4:e2b-it-qat-2k` + облачный fallback для сложных задач
2. **ASR:** Локальный whisper.cpp small — мгновенно, офлайн
3. **TTS:** Локальный Piper с ru_RU-irina — женский голос, мгновенно
4. **VLM:** Облачный `glm-4.5v` — локальный LLaVA не влезет в 4 ГБ VRAM
5. **Embeddings:** Локальный `all-MiniLM-L6-v2` — 25 МБ, мгновенно

С этой конфигурацией U.N.A. будет:
- Отвечать за 1-2 секунды на простые команды
- Работать полностью офлайн (кроме анализа экрана)
- Использовать ~2.5 ГБ VRAM (запас 1.5 ГБ)
- Использовать ~4.5 ГБ RAM (запас 3.5 ГБ)
