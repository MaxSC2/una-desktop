# Исторические записи

Здесь лежат документы, полезные как свидетельства принятых решений, но не описывающие текущее
состояние приложения. Они не должны использоваться как спецификация при разработке.

| Каталог | Содержимое |
|---|---|
| `audits/` | Одноразовые аудиты и проверка старых материалов. |
| `planning/` | Снимки завершённых досок задач и планов. |

Для текущего состояния используйте корневой `HONEST_STATUS.md`, `AGENTS.md`, документацию в `docs/`
и код. Для внешних кандидатов — `docs/research/`.
